Контрольные вопросы:
1.
Ветка - это отдельная "папка" с историей таких сохранений 
Коммит - это сохранение проекта с пояснением
2.
git add - позваляет нам выбрать какой файл сохранять 
git commit - уже сохраняет выбранный файл
3.
флаг -b - создает новую ветку если такой еще нету
4.
Pull request - позваляет команде проверить код не загружая на основную ветку
5.
После слияния ветка никуда не уходит а остается висеть в истории
